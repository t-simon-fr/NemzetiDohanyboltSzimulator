Existing base products remain available exactly as before. Existing identifiers 0–15 and warehouse base ordering remain unchanged; variants append at 16–22. The fixed counter display follows coffee/lottery fixture ownership. Price/slot limits are still shared.

Compatibility: base ids, stock objects, prices and furniture remain; contracts survive day changes and reset only with a new game. UI: third Partners tab inside Shop Management; Orders/Prices show only unlocked supplied goods. Undelivered stock and held stolen stock never create new requests.

Implementation assumption after preference prompt: unit costs remain whole-forint floor(90%); only the final supplier basket payment rounds to the nearest 5 Ft. The UI shows the subtotal and rounding separately, inventory items retain the unrounded unit cost, and ledger profit records the rounding difference once. This follows the existing physical denominations; the user can still steer the pending preference. Fridge partners require the existing self-service expansion; the fixed counter-display partner is independent and can be bought in the starter shop.
