# #134 – Normál polcsorokat összekötő sarokelem

A Sarokpolc a felhasználó pontosítása alapján **1,2×1,2×2,5 m**: mindkét falon egy normál polc szélességét foglalja el. A két csatlakozó oldal 50 cm mély; az öt polclap szintje és 4,5 cm vastagsága egyezik a normál polcéval. Az átlós előlap a normál polcsorok első éleit köti össze. Az ár 6500 Ft, a kapacitás tíz termékhely, üres eladáskor 3250 Ft.

A mesh és a rendező kontúrja közös méretarányt használ. A meglévő fal-/szomszédvonzás mindkét polcsort a sarok mellé illeszti. A bútorok ütközési/lerakási foglalása továbbra is a teljes befoglaló, az NPC-navigáció viszont a levágott első sarok valódi átlós élét követi, a szokásos 29 cm-es biztonsági távolsággal. Ez teszi elérhetővé a csatlakozó normál polcok szélső termékeit is.

A változtatás a #132 sarokpolcot méretezi át. Nem változik a többi bútor, az árak vagy a mentés/megszakítás/eladás szabálya. Pages-kiadás nincs. [Ellenőrzési jelentés](REPORT.md).
